# Dia 7 — Projeto Final

## Tutor Pessoal de Carreira Tech

### 🎯 Objetivo

Criar um Mega-Prompt capaz de analisar meu momento atual de carreira, comparar meu perfil com uma vaga-alvo e gerar um Plano de Desenvolvimento Individual (PDI) de 30 dias.

## 🧩 Técnicas utilizadas

O projeto combina as técnicas estudadas durante os 7 dias:

- PTC (Papel, Tarefa e Contexto)
- Role Prompting
- Few-Shot Prompting
- Análise estruturada
- Delimitadores
- Restrições de saída
- Injeção de contexto longo
- Composição de prompts

## 🏗️ Estrutura

### 1. Persona

Define a mentora responsável por analisar minha carreira.

### 2. Contexto

Apresenta minha formação, certificações, experiência, estudos, objetivo e tempo disponível.

### 3. Base de conhecimento

Contém a vaga-alvo e o relatório de gaps produzido no Dia 6.

### 4. Lógica de análise

Define os critérios utilizados para priorizar os gaps e construir o plano.

### 5. Padrão de saída

Define como as semanas do plano devem ser apresentadas.

### 6. Restrições

Define limites para manter o plano realista e executável.

### 7. Tarefa

Solicita a criação do PDI de 30 dias.

## 🚀 Resultado

O Mega-Prompt gerou um Plano de Desenvolvimento Individual de 30 dias baseado nos gaps identificados na vaga-alvo.

O plano prioriza prática, documentação e construção de evidências no GitHub.

## 💡 Principal aprendizado

Um prompt pode ser construído como um sistema de instruções organizado em camadas.

Cada técnica aprendida durante os sete dias contribuiu para tornar a resposta mais específica, controlada e útil.

## 📌 Próximos passos

O Mega-Prompt pode ser atualizado conforme meu perfil profissional evoluir.

Novas versões poderão ser criadas para comparar mudanças no contexto, nos objetivos e nas prioridades de estudo.

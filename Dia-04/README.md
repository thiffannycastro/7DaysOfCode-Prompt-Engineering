# Dia 4 — Análise Estruturada de Decisão

## 🎯 Objetivo

Aplicar uma estrutura de análise em etapas para avaliar um dilema relacionado à minha transição para cybersecurity.

## 🧠 O que aprendi

Uma decisão complexa pode ser dividida em etapas para evitar conclusões precipitadas.

A estrutura utilizada foi:

1. Reformulação do dilema;
2. Identificação dos critérios;
3. Avaliação das opções;
4. Identificação das informações faltantes;
5. Recomendação final.

## 🔎 Dilema analisado

Decidir entre continuar estudando antes de começar a construir meu portfólio ou começar a construir projetos públicos no GitHub enquanto continuo estudando.

## 💡 Principal aprendizado

Uma análise estruturada permite comparar alternativas com base em critérios relevantes para o meu contexto, em vez de tomar uma decisão apenas por intuição.

Também percebi que identificar quais informações ainda estão faltando pode ser tão importante quanto chegar a uma recomendação.

## 📌 Resultado

A análise recomendou começar a construir o portfólio agora, utilizando os próprios estudos como oportunidade para criar projetos e documentação prática.

## 📚 Técnica utilizada

Análise estruturada de decisão por etapas.
